# ActiveDeliver Next - คำแนะนำ 5 ขั้นตอนสำหรับพี่เต้ (Sydney Courier)

1. ดาวน์โหลดไฟล์ ActiveDeliverNext-Project.zip ลงคอมพิวเตอร์
2. คลิกขวาที่ไฟล์แล้วกด Extract All (แตกไฟล์ ZIP)
3. ดับเบิ้ลคลิกเปิดไฟล์ index.html ใน Google Chrome หรือ Edge (ไม่ต้องลงโปรแกรมเพิ่ม)
4. ทดสอบใช้งานระบบสแกนรับของ ส่งของ ถ่ายรูปจุดวางของพร้อมพิกัด GPS ได้ทันที
5. สำหรับแท็บเล็ต: ส่งไฟล์ index.html เข้าแท็บเล็ต แล้วเปิดด้วย Chrome กด 'Add to Home Screen' เพื่อใช้งานเหมือนแอปจริงได้เลย
